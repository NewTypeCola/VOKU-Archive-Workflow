# 1994 · 전체 입력과 결과

[English](../../../../../../workflow/assets/demo/1994/complete/README.md)

압축을 풀지 않고 아래 링크에서 각 이미지를 바로 열 수 있습니다. 모든 이미지는 원래 해상도를 유지한 WebP이며 품질 90으로 압축했습니다.

개인 이름·연락처·개인 도장과 사인을 가상화한 안전 입력과 그 처리 결과입니다. 공개 인명, 학과·입학년도는 보존했습니다.
