# VOKU Archive History

[English](../../history/README.md)

방송 원고 66,010쪽을 처리하면서 무엇이 막혔고, 그때의 판단과 결과가 다음 작업에 어떻게 전달됐는지를 기록합니다. 이름 발견, 동일인 연결, 기하 처리, 사람 검수, 독립 보정본의 합성은 서로 다른 문제를 남겼습니다. 완료된 결과와 함께 실패·중단·부분 적용·사용자 정정도 보존했습니다.

## 근거를 읽는 방법

실제로 무엇이 만들어지고 적용됐는지는 코드·DB·receipt·manifest·output으로 확인하고, 왜 시도하거나 바꾸었는지는 당시 memory와 사용자 결정에서 찾았습니다. 계획과 후속 실행, 오래된 상태와 현재 결과가 다른 경우에는 각각의 시점과 범위를 남겼습니다. 공개본에는 비식별 설명·집계·선별한 코드가 들어 있으며, 원고·원본 OCR·신원 원장·검토 DB·전체 memory는 포함하지 않았습니다.

이 구분에는 OpenAI Cookbook의 Iterating development workflows with Codex를 참고했습니다. History의 구성은 실제 VOKU의 문제와 전환점을 따릅니다.
