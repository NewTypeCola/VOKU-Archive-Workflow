# 기록의 경계

[English](../../../history/reference/limits.md)

- 초기 PDF→WebP 변환기의 정확한 구현은 연결되지 않았습니다. 현재 game 복사 도구는 이미 존재한 자료의 취합 도구입니다.
- read-v2는 제작 뒤 신규 텍스트 85쪽을 제출했고, read-next도 제작 뒤 82쪽을 실제 제출했습니다. 두 갈래의 주 처리 역이관은 확인되지 않았습니다. [E28](evidence.md#e28), [E29](evidence.md#e29)
- 저장 OCR 줄 재기입 경로의 처리 기록은 존재하지만, 이후 다른 경로로 옮기거나 중단하기로 한 당시 이유는 연결되지 않았습니다. [E34](evidence.md#e34)
- 짧은 호칭 pilot의 최초 발견·요청 경로와 초기 보류 10쪽에 후대 사각형 규칙을 소급할 의도는 기록이 부족합니다.
- 후기 이름 누락 보정의 51/457편성 진행은 저장 STOP 보고와 memory에 근거합니다. 현재 출력 279개는 존재하지만 해당 production 실행 상태 파일은 남아 있지 않습니다. [E31](evidence.md#e31)
- 현재 이미지와 과거 최상위 manifest가 어긋나는 표본은 후속 영수증으로 설명됩니다. 전체 stale 행 수는 재집계하지 않았습니다. [E26](evidence.md#e26)
- 보존 코드는 조사 시점의 snapshot입니다. 출처와 실제 적용 단계는 [코드 목록](../historical/README.md)과 [provenance](../../../history/reference/code-provenance.json)에 기록했습니다.
