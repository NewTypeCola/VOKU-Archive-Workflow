# 공개본의 검증 기록

[English](../../../history/reference/verification.md)

2026-09-27의 사진·문서 편집과 현재 패키지 확인은 [공개본 검증 기록](publication-check.md)에 있습니다. 아래는 각 기준본을 만들 당시의 기록입니다.

## 국소 편집 확인 — history-anchor-v3 · 2026-09-26

- HISTORY·evolution·여섯 사례에서 문단·표·절 구성과 숫자의 순서·등장 횟수를 편집 전과 대조했습니다. 기준본 버전 표기를 제외한 수치는 유지됐습니다.
- 어미 변경과 첫 코드명의 기능 설명을 구분해 대조했습니다. 상세 Mermaid 원문, `limits.md`, 역사 코드와 기존 집계 JSON은 그대로 보존했습니다.
- 이전 공개초안의 데모 검증·재사용 설명을 제거했습니다. History 문서의 링크는 이 패키지 안에 있는 대상만 남겼습니다.
- 변경 파일의 해시를 갱신해 기준본을 고정했습니다. 아래 v2·v1의 수치와 검증 범위는 각 편집 시점의 기록입니다.

## History 영역 정리 — history-anchor-v2 · 2026-09-26

이번 검증은 History의 재배치와 편집에 관한 것입니다. v1에서 대조한 실제 아카이브의 집계와 근거는 아래 기록 및 연결된 JSON에 보존했습니다.

- History 본문, evolution, 여섯 사례, reference, historical의 연결을 새 디렉터리 기준으로 확인했습니다.
- 용어표·문제 분기 및 합류 지도를 본문에 추가했습니다. 지도의 실선은 자료·결정·코드·결과 전달로, 점선은 같은 문제를 다룬 관련 갈래로 구분했습니다.
- 보존 코드 파일의 해시는 [code-provenance](../../../history/reference/code-provenance.json)와 대조했습니다. 기존 집계 JSON과 provenance의 내용도 편집 전 해시와 대조했습니다.
- reference의 근거 항목별 숫자와 문장을 편집 전 내용과 대조했습니다. 본문의 여섯 시기·연표·실패 경로를 보존하면서 분모 설명을 추가했습니다.
- 새 [anchor manifest](../../../history/history-anchor.json)의 파일 해시, repository 루트의 공개 허용 목록, 내부 링크, Python 문법과 공개 텍스트 패턴을 검사했습니다.

### v2 대조 결과

- 공개 파일 40개, History 기준본 파일 32개, 내부 링크 220개와 Python 파일 12개의 문법 검사를 통과했습니다.
- 역사 코드 13개와 기존 집계·코드 출처 JSON 3개는 편집 전과 SHA-256이 같습니다.
- 본문에서 추가한 용어표·지도·분모 설명과 기준본 버전 표기를 되돌려 비교하면, 기존 History 본문의 해시와 일치합니다. 첫 사례는 분모 설명만 보강했으며 나머지 다섯 사례의 해시는 유지됐습니다.
- E01–E35의 각 근거 항목에서 쉼표 표기만 정규화해 수치를 대조했고, 값과 등장 횟수가 유지됐습니다.
- 새 History 지도와 기존 evolution 그림을 Mermaid 12.0.0으로 파싱·렌더링하고 화면을 확인했습니다. 새 지도는 노드 30개·연결선 39개이며 문법·렌더링 오류는 0건이었습니다.

## History 기준본 보강 — history-anchor-v1 · 2026-09-26

- 단일 에이전트 판독 대체본 (read-v2)의 보관 DB와 checkpoint, 세션 입력 대체본 (read-next)의 현재 DB·session·출력, 격리 기하 시험 (tmptest)의 반영 기록, 후기 이름 보정 출력, 최종 누락 조사 보고를 읽기 전용으로 대조했습니다. [추가 집계](../../../history/reference/history-observations.json)
- OCR 줄 재기입 경로는 영수증 59개·644쪽과 출력 210개의 해시를 대조해 일치했습니다. 제작·중간 보고와 후속 실행이 다른 지점을 History에 정정했습니다.
- v1은 HISTORY, 여섯 사례, 근거·집계·코드의 파일 해시를 고정했습니다. 공개 검사기는 해시, 허용 목록, 내부 링크와 코드 provenance를 확인했습니다.
- 기존 조사 입력 297개의 해시와 별도로 기록한 원본 DB·코드·보고서 49개 항목의 해시/mtime이 유지됐습니다. 집합 간에는 중복이 있으며, 검사 대상은 기록한 파일이었습니다.
- v1 편집에서 역사 코드의 해시는 유지됐고 WORKFLOW는 지정한 문장만 삭제했습니다.
- 공개 허용 목록에서 운영체제 메타데이터를 제외했습니다. 공개 텍스트의 경로·credential·운영 ID·이메일 패턴과 비공개 명단 이름을 대조하고, ZIP 구성과 각 파일 해시를 확인했습니다.

## 기초 공개본에서 수행한 검증

같은 날 처음 공개본을 만들 때 수행한 범위입니다. 원래 아카이브의 생산 처리는 다시 실행하지 않았습니다.

- 현재 원본 DB의 상태 집계와 최종 이미지 개수, OCR JSON 5,330개의 66,010쪽·1,992,165줄을 대조했습니다. [비식별 집계](../../../history/reference/current-observations.json)
- 조사 시작 시 해시를 기록한 입력 297개, 보존 코드 원본 13개, 별도로 고정한 DB·보고서 11개가 비교 시점에도 보존돼 있었습니다. 이 집합은 서로 겹칠 수 있으며, 검사 대상은 기록한 파일이었습니다.
- 모든 공개 Python 파일은 원 생산 모듈을 import하지 않고 문법을 검사했습니다. 공개 JavaScript 구문도 검사했습니다. Swift 전체 생산 실행은 수행하지 않았습니다.
- 역사 코드의 배포 해시를 provenance와 대조했습니다. Markdown의 내부 파일 링크와 명시한 근거 anchor를 검사했습니다.
- 개인 홈 절대경로·credential·운영 ID·이메일 패턴을 검사했습니다. 비공개 고정 명단의 고유 이름 267개와 공개 텍스트도 로컬에서 대조했습니다. 한 문장의 붙여쓰기에서 생긴 오탐을 확인해 띄어쓰기를 수정했고, 최종 일치는 0이었습니다.

## 현재 기준본 다시 확인하기

repository 루트에서 다음을 실행합니다. Python 표준 라이브러리만 사용하며 파일을 읽어 검사합니다.

```sh
python3 -B tools/verify_public.py
```

public-files.txt는 현재 공개 파일의 허용 목록입니다. 비공개 조사 자료와 원본 자료는 이 목록에 포함하지 않습니다.
