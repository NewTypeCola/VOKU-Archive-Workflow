루트 소개에 실물 이동·보관·스캔 경위와 대표 사진을 보강했습니다. 사진 18장과 5장 대표 스트립, 네 묶음의 사진 문서를 추가하고 공개 자료의 이용 조건을 MIT-0으로 통일했습니다. 검토 앱은 자기 환경에서 실행하는 정적 샘플로 안내합니다.

사진 18장은 원본의 전체 구도와 가로세로 비율을 유지했습니다. 녹음실 반사와 자동차 배경의 얼굴 네 곳만 블러 처리했으며, 리사이즈·인코딩 전 단계에서 해당 영역 밖의 픽셀을 변경하지 않았음을 확인했습니다. 대표 스트립은 세 번째의 트렁크·넘어진 큐시트와 네 번째의 큐시트 더미가 더 보이도록 조정했습니다.

방향을 적용한 뒤 sRGB로 변환하고 새 RGB 이미지로 저장해 촬영 메타데이터를 넘기지 않았습니다. 개별 사진은 WebP 품질 86, 대표 스트립은 품질 88입니다. 메타데이터 검사는 WebP 파일 내부를 기준으로 하며, 파일 해시는 [History manifest](../../../history/history-anchor.json)에 기록합니다. v5에서는 공개 검사와 사진·문서 표시 검사를 다시 실행했습니다. 앱 기능 검사는 v4에서 실행한 결과이며, 이후 앱 실행 코드와 샘플은 변경하지 않았습니다.

## v4·v5 편집 당시의 보존 확인

원본 사진 18장의 SHA-256은 작업 전후가 같습니다. 보존 코드 13개, 현재 배포 manifest를 제외한 기존 데모 192개, 여섯 사례와 `evolution.md`, 근거·집계·출처 문서 7개, 검토 앱의 로직·샘플·검사·기존 화면 10개와 인간–에이전트 문서도 바이트가 같습니다. `HISTORY.md`는 첫 문단의 기준본·사진 연결만 바꾸었고 이후 본문과 Mermaid 원문을 유지했습니다.

마감 편집으로 기존 공개 파일 18개를 수정하고 26개를 추가했습니다. v5의 사진 구도 조정에서는 기존 파일을 교체하고 관련 문서·해시를 갱신했으며 파일명과 공개 목록은 유지했습니다. 기존 공개 파일을 삭제하지 않았습니다. 원본 파일명 매핑, 작업 중 확대 이미지, 브라우저 검사 기록 등은 공개 목록에 포함하지 않습니다. 이 결과는 로컬 편집·검사에 관한 기록이며 실제 외부 호스팅 검사는 포함하지 않습니다.

## v6 문체 정리와 확인

설명 문서의 본문과 문장형 제목을 존댓말로 통일했습니다. LICENSE·NOTICE와 실제 인용문, 코드·데이터는 유지했습니다. 어미와 1인칭·질문 표현, 기준본 안내를 제외한 기존 내용과 문서 구성을 대조했고, 제목 변경에 따른 링크 앵커를 갱신했습니다.

사진·데모 이미지·OCR·실행 코드와 과거 검증 데이터는 v5와 바이트가 같습니다. 현재 History·Workflow manifest를 갱신한 뒤 공개 파일·링크·해시 검사를 통과했습니다. 이 문체 수정에서 앱 기능 검사는 다시 실행하지 않았습니다.

## 다시 확인하기

저장소 루트에서 다음을 실행합니다. Python 표준 라이브러리만 사용하며 파일을 읽어 검사합니다.

```sh
python3 -B tools/verify_public.py
```

검토 앱의 검사 명령과 필요한 개발 도구는 [검사 안내](../../workflow/assets/human-review/VERIFICATION.md#재확인)에 있습니다. 일반 사용자의 실행 방법은 [로컬 실행 안내](../../workflow/assets/human-review/README.md#로컬에서-실행), 공개 대상은 [파일 목록](../../../public-files.txt)에서 확인합니다.
