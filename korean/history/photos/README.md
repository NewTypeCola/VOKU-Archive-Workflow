## 공개용 정리

사진 18장은 모두 원본의 전체 구도와 가로세로 비율을 유지한, 긴 변 1,600px 이내의 WebP 사본입니다. 영문 파일명을 사용하고 촬영 위치·시간·기기 정보를 포함한 EXIF/XMP 등 메타데이터를 제거했습니다. 녹음실 유리에 반사된 얼굴 두 곳과 자동차 사진의 배경 얼굴 두 곳만 작게 블러 처리했습니다. 작업 책상의 화면·원고에 있던 기존 흐림 처리는 유지했습니다.

루트의 [대표 스트립](../../../history/assets/photos/archive-process-strip.webp)은 책장·카트·자동차·거실·작업 책상의 다섯 장을 같은 높이로 크롭해 붙인 2,520×1,080px 이미지입니다. 개별 사진과 스트립의 이용 조건은 [MIT-0](../../LICENSE.md), 파일·메타데이터 확인 결과는 [공개본 검증 기록](../reference/publication-check.md)에 있습니다.
