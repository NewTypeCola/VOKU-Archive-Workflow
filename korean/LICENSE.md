## 적용 범위

| 자료 | 포함 범위 | 적용 |
|---|---|---|
| 설명 문서 | 루트 소개, Workflow, History, 데모·검토 앱 안내와 검증 설명 | MIT-0 |
| 직접 작성·정리한 코드 | 공개 검사기, 데모 재생 코드, 정적 검토 앱과 검사 코드 | MIT-0 |
| 보존한 과거 코드 | `history/historical/`의 전체 파일·발췌 코드. 당시 형태와 출처 기록을 보존 | MIT-0 |
| 공개용 사진·데모 자산 | `history/assets/photos/`의 사진·대표 스트립, 공개 데모 이미지·가상 표기·설명 데이터와 앱 화면 | MIT-0 |

배포 대상은 [public-files.txt](../public-files.txt)에 명시되어 있다. 이 허락은 프로젝트 작성자가 권리를 가진 부분에 적용되며, 사진·데모에 담긴 제3자의 원고·그림·상표 등 별도 권리를 새로 부여하지 않는다. **실제 아카이브 원고와 66,010페이지 전체 데이터셋은 이 저장소와 별개**이며, 이 문서는 그 전체 자료에 대한 이용허락을 정하지 않는다. 외부 라이브러리·프레임워크의 조건과 코드 출처는 [NOTICE](NOTICE.md)를 참고한다.
