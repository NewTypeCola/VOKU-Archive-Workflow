## Materials not carried into the historical account

The earlier public implementation `written` had an interface reconstructed around a common profile/CLI. It was not treated as VOKU's actual early structure. Its evidence index helped establish source boundaries; this repository did not recombine historical tools into a common runner.

Original notes, databases, memory, and complete source-code archives are not distributed. For the necessary code, the [code inventory](../historical/README.md) identifies provenance and whether it was executed.
