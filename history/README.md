# VOKU Archive History

[한국어](../korean/history/README.md)

This records what blocked the processing of 66,010 pages of broadcast scripts and how the judgments and outputs at each point passed into the next task. Name discovery, identity resolution, geometry, human review, and composition of independent corrections posed different problems. Failures, stops, partial applications, and user corrections are preserved alongside completed outputs.

## How to read the evidence

Code, databases, receipts, manifests, and outputs establish what was actually created and applied. Contemporary memory records and user decisions explain why something was tried or changed. Where plans differed from later execution, or old states from current outputs, each point in time and scope is retained. The public edition includes descriptions without identifying details, aggregates, and selected code; it excludes scripts, original OCR, identity ledgers, review databases, and complete memory records.

This distinction drew on OpenAI Cookbook's Iterating development workflows with Codex. History's structure follows VOKU's actual problems and turning points.
